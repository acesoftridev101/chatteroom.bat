This is chatterroom.bat Download every single file. Edit the code so that in set "NetworkLogFolder=\\YOUR-SERVER-NAME\SharedChatFolder\"                     Make your-server-name the computer name. To find your computer name go into the start menu and type and enter cmd. Then type the command hostname and the input that comes from that command, copy and paste the input and delete YOUR-SERVER-NAMe and make it the input. Also you need to make a folder named SharedChatFolder and give everyone on your network by going in properties --> sharing --> Advanced Sharing --> Permissions, then give read and write permissions to everyone on your network.
